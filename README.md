# homebrew-tap

Homebrew formulae for [wheelerlaw](https://github.com/wheelerlaw) tools.

```
brew install wheelerlaw/tap/clone
brew install wheelerlaw/tap/kc
```

| Formula | Description |
|---|---|
| [clone](https://github.com/wheelerlaw/clone) | Git clone wrapper that organizes repos into a host/org/repo directory layout |
| [kc](https://github.com/wheelerlaw/kc) | Store long secrets in the keychain without the 128-character prompt limit |
